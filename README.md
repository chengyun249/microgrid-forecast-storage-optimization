# 预测与储能反馈协同的微网购电优化

2026 年高教社杯全国大学生数学建模竞赛 C 题《微网与外部电网电力调控策略》的建模研究整理。项目以 **10 分钟区间的供需平衡、储能状态和实际购电费用** 为共同口径，从确定性调度出发，逐步引入负荷与光伏预测、历史误差情景、日内预报更新和波动电价。

本仓库依据[最终论文](paper/final_paper.pdf)组织模型主线，并保留提交支撑材料中的五个独立运行脚本。[论文摘要与正文（Markdown）](paper/article_text.md)可直接在 GitHub 阅读，含公式、结果表与插图；若公式显示异常，可查看[公式源码索引](paper/equations_source.md)。[研究导读](docs/research_guide.md)按四个问题解释模型机制、核心代码和流程图。它是竞赛研究记录，不是已部署的微网控制系统。

## 研究问题与方法主线

在每日 0 时需要先确定购电合同、供需缺口可能触发高价补购的条件下，预测误差会影响储能应保留多少电量，以及何时调整合同。我们的处理顺序是：

```text
统一十分钟能量与储能约束
    ├─ 问题一：已知负荷、光伏、电价 → LP / MILP 确定性调度
    ├─ 问题二：未知负荷与光伏 → 四模型融合预测 → 历史残差情景
    │                              → 分位数购电起点 → DP 储能阈值 → 反馈修正
    ├─ 问题三：0 / 6 / 12 / 18 时预报更新 → 负荷偏差校正
    │          → 条件情景与改约费用 → 六小时滚动合同
    └─ 问题四：波动电价预测与日内校正
               → 固定合同（4-2）/ 可改约合同（4-3）的分别适配
```

### 1. 确定性调度

将功率换算为每个 10 分钟区间的电量，统一建立母线侧供需平衡、储电量递推、容量与充放电功率约束。问题一还要求日末储电量回到初值。分别求解线性规划（LP）和带充放电互斥约束的混合整数线性规划（MILP），并检查两种形式的费用与物理可行性。

### 2. 预测驱动的日前购电

负荷与光伏分别建模：日更 LightGBM、日更 Ridge、周期残差 LightGBM 和日历曲线 Ridge 构成四个基础预测器，依据已完成日期的误差进行融合。再用历史整日残差构造净需求情景，保留日内误差轨迹；以分位数规划确定购电起点，用动态规划（DP）求储能保留阈值，并在相同反馈规则下修正购电曲线。这里优化的是购电与储能的联合费用，预测误差本身不是最终目标。

### 3. 多时刻信息更新

在 0、6、12、18 时利用新发布的光伏预报，并根据当天已观察到的负荷偏差更新后续预测。模型对历史误差情景重新赋权，在改约费用约束下调整下一六小时合同，再按 10 分钟区间执行储能反馈。论文还比较了去掉 18 时更新、逐区间细化等机制。

### 4. 波动电价适配

问题四加入电价融合预测及日内校正。固定全天合同的 **4-2** 使用价格与供需误差配对，允许日内改约的 **4-3** 在日前决策中估计未来改约机会。两种机制对应不同交易权限，因此分别建立和评价。

## 论文报告的主要结果

| 场景 | 评价范围 | 论文中的结果 |
| --- | --- | ---: |
| 问题一：LP / MILP | 题目给定的典型日 | 两种模型最优购电费均为 **35,126.95 元**，较无储能方案降低 **26.90%** |
| 问题二：预测、情景与储能反馈 | 2025-02-01 至 2025-12-31，334 天 | 总费用 **13,475,274.43 元**；其中紧急购电费 **526,386.22 元** |
| 问题三：多时刻预报与滚动改约 | 同上 | 总费用 **13,016,898.13 元**；较同一问题内的直接扩展基准少 **77,754.00 元** |
| 问题四：波动电价 | 同上 | 固定合同 4-2 为 **14,132,392.08 元**；可改约合同 4-3 为 **13,634,348.55 元** |

问题二正式回放的净负荷预测 WAPE 为 **7.624%**。问题四中 4-3 比 4-2 低 **3.5241%**，这个差额包含交易权限、合同调整与相应模型的共同作用，不能单独归因于电价预测。固定电价与波动电价场景的绝对费用也不直接作为方法优劣比较。

论文按区间检查了供需平衡、储电量递推、容量、功率和互斥约束；问题一为 144 个区间，后续正式回放为 48,096 个区间。模型公式、场景定义、费用构成与消融结果见[论文摘要与正文](paper/article_text.md)。

## 结论范围

- 报告数值是模型结构和部分配置在 2025 年同年度数据上开发后进行的逐日回放；尚无独立跨年度测试，不能据此宣称稳定的跨年度费用优势。
- 储能 DP 使用离散状态网格与近似情景分布，后续曲线优化也有近似求解；只有问题一的 LP / MILP 具有对应确定性模型的最优性结论。
- 模型未纳入线路约束、储能退化、控制延迟及更复杂的市场结算规则。移植到真实微网时，需要重新标定并验证。
